# no_fly_zone
STM32-based quadcopter running on custom hardware and custom flight controller software

## /firmware
Contains STM32 libraries, source code, and build settings for remote and quadcopter

### /no_fly_zone
Contains STM32 flight controller software

### /no_fly_zone_remote
Contains remote control software

### /scripts
AI-generated scripts for testing and validating flight controller outputs

### /stm32_lib
Contains all relevant libraries for sensors and peripheral management

## /hardware
Contains KiCAD schematics + PCB designs for remote and quadcopter

## /screenshots
Contains relevant screenshots for those in other READMEs
